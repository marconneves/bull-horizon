Atue como o **Tech Lead** (`.claude/agents/techlead.md`).

Execute `.claude/skills/triage/SKILL.md` para isolar e entender o problema reportado. Siga o fluxo obrigatório definido em `.claude/commands/manager.md`. Não pule etapas.
